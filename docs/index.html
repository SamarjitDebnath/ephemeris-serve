Ephemeris Serve

An LLM inference server with continuous scheduling, dynamic batching, and SSE streaming for token-level outputs.

Quick start API reference View on GitHub

Features

Continuous scheduling

A request queue and continuous scheduler keep the GPU/CPU busy without waiting for a full batch to fill.

Dynamic batching

Streaming and non-streaming batch inference paths both batch requests dynamically for throughput.

SSE token streaming

Server-Sent Events stream decoded tokens as they're generated, for low-latency client rendering.

Cancellation & timeouts

Explicit request cancellation, per-request deadlines, and cache-state fallback handling.

Hot model swap

Swap the loaded model in place via /api/model, draining in-flight requests first — no restart.

Metrics & health

Queue latency, batch size, and token throughput metrics, plus a lightweight FastAPI health check.

Quick start

Prerequisites: Python 3.11+, a supported GPU (optional), and access to the Hugging Face Hub for authenticated model downloads.

python -m venv .venv
source .venv/bin/activate
pip install -U pip
pip install -e .

Run the server for development:

python main.py
# or with uvicorn directly
uvicorn main:app --host 0.0.0.0 --port 8000 --reload

CLI chat client

ephemeris-serve ships two subcommands: serve starts the inference server, and start is a REPL that talks to an already-running server over /api/generate's SSE stream.

# start the server in one terminal
ephemeris-serve serve
ephemeris-serve serve --model Qwen/Qwen2.5-0.5B

# chat with it from another terminal
ephemeris-serve start
ephemeris-serve start --host 127.0.0.1 --port 8000 --max-tokens 128 --creativity creative

--creativity picks a friendly sampling-temperature preset (deterministic, balanced, creative, high-freedom); both the model and the creativity level can be changed mid-session with /model and /creativity.
